- Members can play on one device and control it from the web or the phone. Other signed-in
  devices show that playback and can pause, seek, skip, or move it. Routes live under
  `/account/playback`. The API requires `PLAYBACK_PRESENCE_LEAVE_GRACE_MS` (the base `api.env`
  sets 5000). An overlay that replaces the API env must set it
- Browse, Subscribed, and Recommendations share chips, lists, and grids. A chip selects
  immediately and the list shows a spinner until the new page arrives. Livestream lists are newest
  live first, then soonest scheduled, and omit scheduled items more than a day past. Search and
  filters clear with an X. Playlists can filter All, Podcasts, or Music. The footer links to a
  public Developer page served from `GET /managed-copy/developer`
- The player settings are a More menu. On a narrow web window the progress line sits on the top
  edge of the bar. Item dates include the local time. Transcripts highlight the current cue and
  can follow playback. On the phone, lists load further pages as you scroll, Home opens
  notifications and Search from the title bar, and For Me opens Recommendations
- Notifications are one line with artwork and a time. Settings group inbox, push, and banner by
  category. A liveItem whose status is missing, or not pending, live, or ended, is not saved
- Add by RSS keeps one episode across devices, with its own pages. Taste Profile is the listen
  opt-in. Sign-in is a server session you can review and end. A personal API key is shown once. A
  missing show, episode, clip, or playlist is a 404. Removed episodes stay as Content Removed
- Operators: drop and recreate the database before the first boot of this version. Bootstrap then
  applies `0001_app_schema.sql` and `0001_management_schema.sql`. Set
  `API_EXPECTED_MIGRATION_FILENAME` and `MANAGEMENT_API_EXPECTED_MIGRATION_FILENAME` to those
  names. Rename `POPULARITY_TRACKING_AGREEMENT_VERSION` to `TASTE_PROFILE_AGREEMENT_VERSION` and
  `NEXT_PUBLIC_POPULARITY_TRACKING_AGREEMENT_VERSION` to
  `NEXT_PUBLIC_TASTE_PROFILE_AGREEMENT_VERSION` (default `2026-10-21`). Remove
  `AUTH_JWT_EXPIRATION`, `AUTH_MOBILE_ACCESS_TOKEN_EXPIRATION`,
  `AUTH_MOBILE_REFRESH_TOKEN_EXPIRATION`, and `NEXT_PUBLIC_SIDEBAR_GROUP_ORDER`. Session length is
  `AUTH_SESSION_IDLE_EXPIRATION` (31536000). Access tokens are `AUTH_ACCESS_TOKEN_EXPIRATION`
  (900). Listen records are kept `STATS_TRACK_EVENT_RETENTION_DAYS` (90). After the wipe, recreate
  the management superuser and billing rows. `BILLING_SANDBOX_GRANT_ALL=true` grants Premium for
  every sandbox purchase on a test deployment only. This cut adds no new migrations
