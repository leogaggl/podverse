# Mobile store release notes

User-facing notes for Play and the App Store. GitHub uses `release-notes/X.Y.Z.md`.

`X.Y.Z.md` is the shared text for both stores. Add `X.Y.Z.ios.md` or
`X.Y.Z.android.md` only when that store should differ. Update the same files
across builds of one version. Keep each file to 500 characters or fewer.
