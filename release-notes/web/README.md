# Web release notes

User-facing notes for the web app. GitHub uses `release-notes/X.Y.Z.md`; the
stores use `release-notes/mobile/X.Y.Z.md`.

`X.Y.Z.md` lists changes a web user would notice, at most six bullets. Update
the same file across staging cuts of one version. The web app does not display
these notes yet, and no publish step requires them.

Agents write these files with abcreleasenotes, from entries in
`release-notes/scratchpad.md`.
