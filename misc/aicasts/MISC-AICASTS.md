# `misc/aicasts/`

Two-voice training scripts (Claire and Tom) that walk through one Podverse feature, written for an
AI audio service. The operator asks for them with **abcaicast**. They are listening material for
people, not technical docs and not agent guidance.

- Each file opens with a header block: what it covers, whether the work was built or planned when
  it was written, its series, its sources, and its length. Read those headers to see what has
  already been covered.
- A series shares a slug and a part number: `<series-slug>-<n>-<slug>.md`.
- The **Status** line reflects the code when the cast was written. Check the code before relying
  on an older cast.
- How to write one: [abcaicast skill](/.cursor/skills/abcaicast/SKILL.md).
