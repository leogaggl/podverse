Une clé permet à un script ou à un agent d'agir pour votre compte {brand_name}. Connectez-vous,
ouvrez Paramètres, puis choisissez Développeur. Créez une clé et copiez-la lorsqu'elle s'affiche.
Elle n'est affichée qu'une fois. Envoyez-la dans un en-tête Authorization Bearer.

Créer une clé nécessite un abonnement. Tant que l'abonnement est expiré, chaque clé est refusée.

Une clé ne peut pas créer ni révoquer des clés d'API, changer votre mot de passe ou votre adresse
e-mail, supprimer votre compte, ni acheter un abonnement.

Chaque clé n'a que les permissions que vous lui accordez, comme lire votre file ou mettre à jour
une playlist. La référence indique chaque endpoint et la permission qu'il exige.
