Una clave permite que un script o un agente actúe en tu cuenta de {brand_name}. Inicia sesión, abre
Configuraciones y elige Desarrollador. Crea una clave y cópiala cuando se muestre. Se muestra una
sola vez. Envíala como encabezado Authorization Bearer.

Crear una clave requiere una membresía. Mientras la membresía esté vencida, se rechaza cada clave.

Una clave no puede crear ni revocar claves de API, cambiar tu contraseña o correo, eliminar tu
cuenta ni comprar una membresía.

Cada clave solo tiene los permisos que le otorgas, como leer tu cola o actualizar una lista de
reproducción. La referencia enumera cada endpoint y el permiso que necesita.
