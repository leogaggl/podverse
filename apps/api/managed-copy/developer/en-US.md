A key lets a script or agent act for your {brand_name} account. Sign in, open Settings, and
choose Developer. Create a key and copy it when it is shown. It is shown once. Send it as an
Authorization Bearer header.

Creating a key requires a membership. While the membership is expired, every key is refused.

A key cannot create or revoke API keys, change your password or email, delete your account, or buy
a membership.

Each key only has the permissions you grant, such as reading your queue or updating a playlist. The
reference lists every endpoint and the permission it needs.
