Ένα κλειδί επιτρέπει σε ένα σενάριο ή έναν πράκτορα να ενεργεί για τον λογαριασμό σας στο
{brand_name}. Συνδεθείτε, ανοίξτε τις Ρυθμίσεις και επιλέξτε Προγραμματιστής. Δημιουργήστε ένα κλειδί
και αντιγράψτε το όταν εμφανιστεί. Εμφανίζεται μία φορά. Στείλτε το ως κεφαλίδα Authorization Bearer.

Η δημιουργία κλειδιού απαιτεί συνδρομή. Όσο η συνδρομή έχει λήξει, κάθε κλειδί απορρίπτεται.

Ένα κλειδί δεν μπορεί να δημιουργήσει ή να ανακαλέσει κλειδιά API, να αλλάξει τον κωδικό ή το email
σας, να διαγράψει τον λογαριασμό σας ή να αγοράσει συνδρομή.

Κάθε κλειδί έχει μόνο τα δικαιώματα που του δίνετε, όπως την ανάγνωση της ουράς σας ή την ενημέρωση
μιας λίστας αναπαραγωγής. Η αναφορά παραθέτει κάθε endpoint και το δικαίωμα που χρειάζεται.
